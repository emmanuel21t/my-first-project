# Simple Interest Calculator

A simple interest calculator project that calculates interest earned or paid on a principal amount over time without compounding.

## Formula

$$\text{Simple Interest } (SI) = \frac{P \times R \times T}{100}$$

- **$P$**: Principal amount
- **$R$**: Annual interest rate (in %)
- **$T$**: Time period (in years)

Total Amount: $A = P + SI$

## Features
- Calculates simple interest from principal, rate, and time inputs.
- Shows the total amount payable or receivable.
